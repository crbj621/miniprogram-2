## 输入框与对齐规则

- 普通表单与弹窗使用 `adjust-position=true` 和光标间距；固定区域的 textarea 标记 `fixed=true`。密码使用原生 `password` 属性。
- 输入框祖先不加按压缩放、居中 transform 或背景模糊；按钮保留科技光效和按压反馈。长弹窗使用外层 flex 居中、内层有界滚动，标题与操作区不挤压。
- 聊天、评论保持列表和输入区在同一个有界布局内，使用 `adjust-position=false` 与键盘控制器，避免系统上移和手动上移叠加。高度按未弹键盘基线与当前窗口共同限制；安卓已缩小窗口时不再次扣高度。
- 单行编辑器和搜索按钮明确高度；文本列 `min-width:0`，头像与操作按钮不收缩。首页同排卡片操作区齐平；管理员表单等宽，金额编辑保留 `0.` 等草稿，提交时才转数字。
- `style:v2` 原生按钮默认 `width:184px`、左右自动外边距。需要自定义尺寸的按钮使用容器加控件类的选择器覆盖宽度与左右间距；行内按钮明确 `width:auto`，不使用全局强制满宽。浏览器转换检查也注入这条默认规则，避免样例正常而微信端变窄。
- 发送失败保留草稿，发送中保护后来输入的内容；较早的消息列表请求不能覆盖刚发送成功的消息。评论同样保护请求期间的新文字和回复对象。
- 开发者工具 / 安卓真机核对：中文候选栏高度变化、返回键收起、连续聚焦、切后台再返回、长表单滚动、私信与评论发送失败；单靠编译和浏览器转换不能确认实体键盘表现。

适配参照 [Tencent TDesign 小程序原生输入实现](https://github.com/Tencent/tdesign-miniprogram/tree/develop/packages/components/input) 和 [微信官方示例](https://github.com/wechat-miniprogram/miniprogram-demo)，沿用原生控件与键盘属性，不为局部样式修复引入整套 UI 依赖。
